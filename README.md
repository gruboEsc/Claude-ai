# Claude-ai — собеседник в Telegram

Бот-друг по переписке для тех, кому не с кем поговорить — на 10 языках. Работает на Claude
(по умолчанию `claude-sonnet-5-5`), доступ — по подписке через Telegram Stars.

## Как он общается

- **Как живой человек в мессенджере**: коротко, по-разговорному, со своим характером,
  мнениями и юмором. Длинную мысль разбивает на несколько сообщений и «печатает» их.
- **Подстраивается под человека**: понимает, что нужно сейчас — выговориться, утешение,
  совет, посмеяться, — и отвечает на это. Перенимает манеру: длину сообщений, «ты»/«вы»,
  эмодзи.
- **Помнит**: сам записывает важное — имя, близких, работу, увлечения, события с датами,
  что помогает, когда плохо, каких тем не касаться. Когда переписка дорастает до
  `COMPACT_AT_TOKENS` (50 тыс. токенов), старая часть сворачивается в подробную сводку
  (кто человек, его история по датам, что происходит сейчас, как с ним общаться, ваши шутки,
  последние 10 сообщений дословно), а заметки заново подставляются в промпт — так контекст
  не теряется, а каждое сообщение остаётся дешёвым.
- **Пишет первым**: планирует сообщения сам («завтра собеседование» → вечером спросит, как
  прошло), ставит напоминания по просьбе, а если человек долго молчит — напишет сам
  (подписчикам, не чаще раза в день, днём, максимум два раза без ответа; выключается в
  `/settings`).
- **Лёгкий флирт** — только если человек сам этого хочет, без откровенного контента; с
  несовершеннолетними — только дружба.
- Понимает фото и стикеры, может поискать что-то в интернете.

## Языки и страны

Язык определяется по настройкам Telegram (сменить — `/language`). Для каждого языка — свой
собеседник, который разделяет местную культуру, и свои нормы общения:

| Язык | Она / он | Цены |
|---|---|---|
| Русский | Аня / Макс | ₽ (ЮKassa) и ⭐ |
| English | Mia / Leo | ⭐ |
| 日本語 | ユイ / レン | ⭐ |
| 한국어 | 서연 / 민준 | ⭐ |
| 中文 | 小雨 / 子轩 | ⭐ |
| Bahasa Indonesia | Putri / Raka | ⭐, регион 2 |
| Tiếng Việt | Linh / Minh | ⭐, регион 2 |
| हिन्दी | Priya / Arjun | ⭐, регион 2 |
| Қазақша | Айгерим / Арман | ⭐, регион 2 |
| Oʻzbekcha | Madina / Jasur | ⭐, регион 2 |

С любым другим языком интерфейс на английском, а собеседник всё равно отвечает на языке
человека. Регион 2 — страны с доходами ниже: там свои цены в звёздах и пропорционально
меньший лимит расходов, чтобы маржа была не хуже. Переводы машинные: перед большим запуском
в стране дай их проверить носителю (`bot/i18n.py`).

Япония и Корея почти не пользуются Telegram (там LINE и KakaoTalk) — для них следующим
этапом нужен отдельный бот на том же ядре.

## Что заложено для безопасности

- На прямой и серьёзный вопрос «ты человек?» честно отвечает, что он ИИ. Это требуют
  правила Anthropic, и это честно по отношению к человеку.
- Если человек пишет о мыслях о самоубийстве или самоповреждении — отвечает бережно и даёт
  телефоны помощи его страны (Россия, Казахстан, Япония, Корея, Китай, Индия, Индонезия,
  Вьетнам, Филиппины, США, Великобритания; для остальных — местная служба и findahelpline.com).
- Не ревнует, не вызывает чувство вины, не удерживает в переписке и поддерживает живое
  общение человека с другими людьми.
- `/forget` стирает всю переписку и память.

## Подписка

- Первые `FREE_MESSAGES` (30) сообщений бесплатно.
- Дальше — подписка, два тарифа:

  | Тариф | Картой / СБП (ЮKassa) | Telegram Stars |
  |---|---|---|
  | 2 недели | 990 ₽ | 650 ⭐, разово |
  | Месяц | 1790 ₽ | 1150 ⭐, с автопродлением |

  Цены меняются в `.env`. Подписки Stars в Telegram бывают только на 30 дней, поэтому
  2 недели за звёзды — разовая оплата.
- **ЮKassa**: картой, через СБП или SberPay, с чеком на email (54-ФЗ). Бот сам проверяет
  статус платежа раз в минуту (вебхук-сервер не нужен), есть кнопка «Я оплатил».
  Автопродление с сохранённой карты (того же тарифа) включается `YOOKASSA_AUTOPAY=1` —
  только после того, как ЮKassa подключит магазину автоплатежи.
- ⚠️ По правилам Telegram цифровые услуги в ботах продаются за Stars; приём рублей — на
  твой риск.
- **Лимит на подписчика**, чтобы один человек не съел весь бюджет: не больше
  `DAILY_LIMIT_USD` ($0.60) в день и не больше `AVG_DAILY_LIMIT_USD` ($0.40) × дней тарифа
  за оплаченный срок ($12 за месяц, $5.60 за 2 недели). Дойдя до лимита, бот по-доброму
  говорит, когда можно продолжить, и не пишет первым.
- `/status` — состояние подписки и отмена продления; `/terms` и `/paysupport` — условия и
  поддержка, Telegram требует их для платежей.
- `/admin` (для `ADMIN_IDS`) — пользователи, подписчики, выручка в Stars, расход на API.
  Админы пользуются ботом без ограничений.

## Быстрый старт

1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Получи ключ API в [console.anthropic.com](https://console.anthropic.com/).
3. Настрой и запусти:

```bash
cp .env.example .env        # впиши токены, ADMIN_IDS и SUPPORT_CONTACT
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

### На сервере (работает круглосуточно)

Нужен VPS с Ubuntu **за пределами России** (Нидерланды, Германия, Финляндия): Claude API не
обслуживает российские IP. Хватит самого дешёвого тарифа (1 CPU, 1 ГБ RAM).

```bash
ssh root@IP_СЕРВЕРА
apt-get update && apt-get install -y git
git clone -b claude/telegram-bot-wyp72j https://github.com/gruboEsc/Claude-ai.git companion-bot
cd companion-bot
bash scripts/setup_server.sh   # первый раз создаст .env и попросит его заполнить
nano .env                      # вписать токены, сохранить: Ctrl+O, Enter, Ctrl+X
bash scripts/setup_server.sh   # ставит Docker, запускает бота, включает бэкапы
```

После этого бот работает сам и перезапускается после сбоев и перезагрузок сервера.

| Что | Команда |
|---|---|
| Логи | `docker compose logs -f` |
| Обновить до свежего кода | `bash scripts/update.sh` |
| Перезапустить (после правки `.env`) | `docker compose up -d` |
| Остановить | `docker compose down` |
| Бэкап базы сейчас | `bash scripts/backup.sh` |

Бэкап базы делается каждый день в 04:00 в папку `backups/` и хранится 14 дней. Время от
времени скачивай свежий бэкап к себе: `scp root@IP_СЕРВЕРА:companion-bot/backups/*.gz .`

Все настройки описаны в `.env.example`: имя и пол собеседника (`COMPANION_NAME`,
`COMPANION_GENDER`), цена, длина пробного периода, когда писать первым, модель и глубина
размышлений.

## Устройство

```
bot/
  __main__.py   запуск
  handlers.py   команды, сообщения, оплата
  billing.py    подписка через ЮKassa: оплата по ссылке, проверка статуса, продление
  yookassa.py   клиент API ЮKassa
  brain.py      ответ собеседника, отправка «пузырями», сообщения первым
  companion.py  характер и правила собеседника (системный промпт)
  tools.py      память, запланированные сообщения, часовой пояс — инструменты для Claude
  claude.py     запросы к Claude: кэш, сжатие длинных диалогов, запасная модель
  db.py         SQLite: пользователи, переписка, заметки, планы, платежи
```

Тесты: `pip install pytest && pytest`
