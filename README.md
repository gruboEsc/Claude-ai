# Claude-ai — собеседник в Telegram

Бот-друг по переписке для тех, кому не с кем поговорить. Работает на Claude
(по умолчанию `claude-opus-5-5`), доступ — по подписке через Telegram Stars.

## Как он общается

- **Как живой человек в мессенджере**: коротко, по-разговорному, со своим характером,
  мнениями и юмором. Длинную мысль разбивает на несколько сообщений и «печатает» их.
- **Подстраивается под человека**: понимает, что нужно сейчас — выговориться, утешение,
  совет, посмеяться, — и отвечает на это. Перенимает манеру: длину сообщений, «ты»/«вы»,
  эмодзи.
- **Помнит**: сам записывает важное — имя, близких, работу, увлечения, события с датами,
  что помогает, когда плохо, каких тем не касаться. Память переживает даже очень длинную
  переписку.
- **Пишет первым**: планирует сообщения сам («завтра собеседование» → вечером спросит, как
  прошло), ставит напоминания по просьбе, а если человек долго молчит — напишет сам
  (подписчикам, не чаще раза в день, днём, максимум два раза без ответа; выключается в
  `/settings`).
- **Лёгкий флирт** — только если человек сам этого хочет, без откровенного контента; с
  несовершеннолетними — только дружба.
- Понимает фото и стикеры, может поискать что-то в интернете.

## Что заложено для безопасности

- На прямой и серьёзный вопрос «ты человек?» честно отвечает, что он ИИ. Это требуют
  правила Anthropic, и это честно по отношению к человеку.
- Если человек пишет о мыслях о самоубийстве или самоповреждении — отвечает бережно и даёт
  телефоны помощи (112, 8-800-2000-122, 051).
- Не ревнует, не вызывает чувство вины, не удерживает в переписке и поддерживает живое
  общение человека с другими людьми.
- `/forget` стирает всю переписку и память.

## Подписка

- Первые `FREE_MESSAGES` (30) сообщений бесплатно.
- Дальше — подписка через Telegram Stars: `PRICE_STARS` (499 ⭐) за 30 дней с автопродлением.
  Цифровые услуги в Telegram продаются только за Stars.
- `/status` — состояние подписки и отмена продления; `/terms` и `/paysupport` — условия и
  поддержка, Telegram требует их для платежей.
- `/admin` (для `ADMIN_IDS`) — пользователи, подписчики, выручка в Stars, расход на API.
  Админы пользуются ботом без ограничений.

## Быстрый старт

1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Получи ключ API в [console.anthropic.com](https://console.anthropic.com/).
3. Настрой и запусти:

```bash
cp .env.example .env        # впиши токены, ADMIN_IDS и SUPPORT_CONTACT
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

### Docker

```bash
docker build -t companion-bot .
docker run -d --restart=always --env-file .env -v $(pwd)/data:/app/data companion-bot
```

Все настройки описаны в `.env.example`: имя и пол собеседника (`COMPANION_NAME`,
`COMPANION_GENDER`), цена, длина пробного периода, когда писать первым, модель и глубина
размышлений.

## Устройство

```
bot/
  __main__.py   запуск
  handlers.py   команды, сообщения, оплата
  brain.py      ответ собеседника, отправка «пузырями», сообщения первым
  companion.py  характер и правила собеседника (системный промпт)
  tools.py      память, запланированные сообщения, часовой пояс — инструменты для Claude
  claude.py     запросы к Claude: кэш, сжатие длинных диалогов, запасная модель
  db.py         SQLite: пользователи, переписка, заметки, планы, платежи
```

Тесты: `pip install pytest && pytest`
